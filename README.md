# 🎵 VoiceTuner 프런트엔드  
사용자가 프로그램 외부에서도 AI 기반 맞춤형 피드백을 확인하고 연습 영상을 추천받을 수 있도록 설계된 **React 기반 웹 페이지**입니다.

---

## 📜 1. 프로젝트 소개

VoiceTuner 웹페이지는 PC와 모바일에서 간단하고 직관적인 인터페이스를 제공합니다.  
**실시간 음성 데이터와 AI 서버에서 처리된 결과를 확인**할 수 있고, **맞춤형 연습 영상을 제공**합니다.

## 🎯 3. 주요 기능
1. **사용자 피드백 조회**  
   백엔드 API를 활용하여 AI 서버가 제공한 맞춤형 피드백 데이터를 실시간으로 확인 가능.
   
2. **맞춤형 연습 영상 추천**  
   YouTube Data API를 사용하여 사용자의 피드백에 적합한 연습 영상을 추천.

3. **반응형 디자인**  
   모바일과 데스크톱 모두에서 최적의 사용자 경험을 제공.
